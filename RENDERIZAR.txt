Comandos para renderizar os arquivos XML e gerar o livro LFS em vários formatos


1 - Para a versão SystemV do livro:


export REV="sysv"
echo "${REV}"
export BASEDIR="$( mktemp --directory )"
echo "${BASEDIR}"
( time make -j1 V=1 L=pt_BR REV="${REV}" BASEDIR="${BASEDIR}" nochunks 2>&1 | tee "${HOME}"/$(date "+%Y-%m-%d-%H-%M-%S")-make_nochunks-"${REV}".log.txt && exit "${PIPESTATUS}" )
cd "${BASEDIR}"
mv -v LFS-BOOK.html LFS-SYSV-BOOK-13.0-pt_BR-NOCHUNKS.html
lynx -dump LFS-SYSV-BOOK-13.0-pt_BR-NOCHUNKS.html 1> LFS-SYSV-BOOK-13.0-pt_BR-NOCHUNKS.txt
cd "${OLDPWD}"
rm -rf "${BASEDIR}"
export BASEDIR="$( mktemp --directory )"
make BASEDIR=/tmp/1 pdf  # Obs.: gerará PDF com páginas tamanho "letter".
cd "${OLDPWD}"
tar --create --file="${HOME}"/caminho/repos/local/LFS-SYSV-BOOK-13.0-pt_BR-HTML.tar --wildcards .
xz --verbose "${HOME}"/caminho/repos/local/LFS-SYSV-BOOK-13.0-pt_BR-HTML.tar


Observação: "make dist" executará todas as instruções acima automatizadamente.

LFS-SYSV-BOOK-13.0-pt_BR-MD5SUMS.txt
LFS-SYSV-BOOK-13.0-pt_BR-SHA1SUMS.txt

3 - Usando-se o repositório proveniente do servidor de traduções do projeto Linux From Scratch:

git clone https://git.linuxfromscratch.org/fr-lfs.git fr-lfs-git
cd fr-lfs-git
cd lfs
( time make -j1 V=1 L=pt_BR REV=systemd BASEDIR="${HOME}"/systemd genhtml 2>&1 | tee "${HOME}"/$(date "+%Y-%m-%d-%H-%M-%S")-make_genhtml-nochunks-systemd.log.txt && exit "${PIPESTATUS}" )

Observação: "make release" gerará todos os formatos, porém tentará copiar os arquivos gerados para o servidor remoto.
